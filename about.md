## How this site is organised

- `_posts/` — one Markdown file per challenge.
- `_events/` — one Markdown file per CTF; writeups link to it with `event:`.
- Categories and tags are read straight from each writeup's front matter.

See `README.md` in the repository for the full "add a writeup" recipe.
