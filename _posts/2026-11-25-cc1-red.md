# Recap

## Extra notes

These are some common tools that you might come across, good to know them.

> **Tooling**
> [GTFObins](https://gtfobins.org/#v) for shell escapes and challenges alike;
> [CyberChef](https://gchq.github.io/CyberChef/) for general CTF needs, it cooks;
> [BurpSuite](https://portswigger.net/burp) for some web challenges, not exactly needed but that's what beginners say about debuggers too;
> [strings](https://linux.die.net/man/1/strings) print the strings of printable characters in files. Generally useful;
> [ffuf](https://www.kali.org/tools/ffuf/#ffuf-1) web fuzzer, allows typical directory discovery;
> [nmap](https://www.kali.org/tools/nmap/#nmap-1) very common for recon;
> [john](https://www.kali.org/tools/john/#john-1) John is cool, tool designed to help systems administrators to find weak (easy to guess or crack through brute force) passwords;
> [wireshark](https://www.kali.org/tools/wireshark/#wireshark-1) must-have for 'pcap' and 'pcapng' files. Packet analysis;
> [binwalk](https://www.kali.org/tools/binwalk/#binwalk-1) Tool for searching binary images for embedded files and executable code, useful to check for polyglot files;
> [Sleuthkit](https://wiki.sleuthkit.org/TSK-Tool-Overview/) Disk image forensics;
> [Firefox](https://en.wikipedia.org/wiki/Internet_Explorer) *?*
> [Ghidra](https://www.kali.org/tools/ghidra/#ghidra-1) Go-to free software for reverse-engineering;
> [Exploit-db](https://www.exploit-db.com/) Database of exploits, comes in handy;
> [Audacity](https://www.audacityteam.org/) Basic audio waveform analysis;
> [xxd](https://linux.die.net/man/1/xxd) hex viewer for files;
> [bvi](https://linux.die.net/man/1/bvi) visual editor for binary files;
